# Spec Kit

このリポジトリは、[Spec Kit](https://github.com/github/spec-kit)の検証として勤怠管理システムを構築しています。

## 概要

Spec Kitは仕様駆動開発を支援するツールキットです。このリポジトリでは、実際の業務アプリケーション（勤怠管理システム）を開発することで、Spec Kitの有効性を検証しています。

## 検証プロジェクト：勤怠管理システム

- 従業員の出勤・退勤記録機能
- 管理者向け勤怠管理機能
- 製品サイトとサポートサイト
- モノレポ構成での管理
- 日本語・英語の多言語対応
- レスポンシブデザイン対応
